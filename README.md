# 🧪 Chemical Reaction Assistance AI

An AI-powered Chemistry Reaction Assistant that interacts with users through text and image inputs, understands chemistry-related queries, and automatically converts chemical structure images into valid LaTeX ChemFig code using OCR, Deep Learning, RDKit validation, Retrieval-Augmented Generation (RAG), and Local Language Models.

## 🚀 Features

* Chemistry Question Answering
* Image-based Chemical Structure Recognition
* OCR-based Atom and Bond Extraction
* Automatic ChemFig Code Generation
* RDKit Chemical Validation
* Retrieval-Augmented Generation (RAG)
* Local LLM Integration
* Interactive Learning Assistant
* Text and Image Query Support

## 🏗️ System Workflow

1. User uploads a chemical structure image or asks a chemistry question.
2. OCR extracts chemical symbols and structural information.
3. Deep learning models analyze the structure.
4. RDKit validates the generated molecular representation.
5. ChemFig code is generated automatically.
6. RAG retrieves relevant chemistry knowledge from textbooks.
7. Local LLM generates explanations and answers.
