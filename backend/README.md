# Chemical Reaction Assistance AI

An AI-powered Chemistry Reaction Assistant that interacts with users through text and image inputs, understands chemistry-related queries, and automatically converts chemical structure images into valid LaTeX ChemFig code using OCR, Deep Learning, RDKit validation, Retrieval-Augmented Generation (RAG), and local LLMs.

## Features

- Chemistry Question Answering
- Chemical Structure Recognition
- OCR-based Atom Extraction
- ChemFig Code Generation
- RDKit Chemical Validation
- RAG-based Knowledge Retrieval
- Local LLM Integration using Ollama
- Image Upload Support
- Interactive Learning Assistant
